# 🗺️ DealsMapApp - تطبيق العروض والخدمات

تطبيق عروض وخدمات مع خريطة تفاعلية وملاح GPS لإيجاد المحلات والعروض بالقرب منك.

## ✨ المميزات الرئيسية

- 📍 **خريطة تفاعلية** - عرض المحلات على الخريطة مع تحديد موقعك
- 🧭 **ملاح GPS** - الملاح لأقرب محل من موقعك
- 📏 **حساب المسافة** - عرض المسافة بينك وبين كل محل
- 🎯 **عروض مخصصة** - عروض تبعاً لقربك من المحلات
- ⭐ **التقييمات والتعليقات** - تقييم المحلات والعروض
- 🏪 **إدارة المحلات** - لصاحب المحل إضافة وإدارة عروضه

## 🛠️ البنية التقنية

### Backend
- **Node.js + Express.js** - خادم الويب
- **MongoDB** - قاعدة البيانات
- **JWT** - المصادقة والتفويض
- **Geolocation API** - معالجة الإحداثيات الجغرافية

### Frontend
- **React** - واجهة المستخدم
- **Leaflet** - الخرائط التفاعلية
- **Axios** - طلبات API
- **Tailwind CSS** - التصميم

## 📦 التثبيت

### متطلبات النظام
- Node.js (v14+)
- MongoDB (محلي أو سحابي)
- npm أو yarn

### خطوات التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/abdelkadergarn46-eng/DealsMapApp.git
cd DealsMapApp

# تثبيت المتطلبات
npm install

# إنشاء ملف .env
cp .env.example .env

# ملء بيانات الاتصال بـ MongoDB والإعدادات الأخرى
# عدل .env حسب احتياجاتك

# تشغيل الخادم
npm run dev
```

## 📚 API Endpoints

### المصادقة
- `POST /api/auth/register` - التسجيل
- `POST /api/auth/login` - تسجيل الدخول

### المحلات
- `GET /api/stores/nearby` - الحصول على المحلات القريبة
- `GET /api/stores/:id` - الحصول على تفاصيل محل
- `POST /api/stores` - إنشاء محل جديد (صاحب المحل)
- `PUT /api/stores/:id` - تحديث محل
- `DELETE /api/stores/:id` - حذف محل

### العروض
- `GET /api/offers` - الحصول على جميع العروض
- `GET /api/offers/:id` - الحصول على عرض محدد
- `POST /api/offers` - إنشاء عرض جديد
- `PUT /api/offers/:id` - تحديث عرض
- `DELETE /api/offers/:id` - حذف عرض
- `GET /api/offers/store/:storeId` - عروض محل معين

## 👥 أنواع المستخدمين

1. **المستخدم العادي** - يمكنه عرض المحلات والعروض
2. **صاحب المحل** - يمكنه إدارة محله وعروضه
3. **الإدارة** - لديه صلاحيات كاملة

## 📱 معلومات الموقع

التطبيق يستخدم:
- **Haversine Formula** لحساب المسافة بين نقطتين
- **GeoJSON** لتخزين الإحداثيات الجغرافية
- **Geospatial Indexes** لتسريع البحث الجغرافي
